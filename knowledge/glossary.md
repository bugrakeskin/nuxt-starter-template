# Local terms

| Term | Meaning |
| --- | --- |
| Starter | Generic source baseline; not an admitted Customer application. |
| Base layer | Reusable Nuxt layout/theme foundation without domain features. |
| Project binding | Verified repository identity after authorized allocation/admission. |
| Starter provenance | Original starter remote and source commit retained after cloning. |
| Delivery contract | Source declarations for build/artifact/runtime roles, not execution authority. |

An OKF bundle is the repository-local knowledge/ directory. A concept ID is local to that bundle; project scope is a memory layer, not tenant authorization. The arc42 profile is the shared minimum document model, not a custom CLI extension.

Read [overview](overview.md), [system](contracts/system.md) and [decisions](decisions.md).

Project visual design is the reviewed brand/theme/component foundation owned by [design](design.md), distinct from the shared SDLC Design stage. Starter product intent in [product](product.md) describes the reusable baseline until it is explicitly rebound to an admitted project.
